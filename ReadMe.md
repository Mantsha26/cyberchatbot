# CyberGuard

## Cybersecurity Awareness Chatbot


## Project Overview

**CyberGuard** is a professional cybersecurity awareness chatbot developed using **C# and Windows Forms** in **Visual Studio**. The application is designed to educate users about common online threats through an interactive, user-friendly conversational experience.

The system provides real-time cybersecurity guidance, personalized responses, sentiment-aware interaction, and topic-based educational support to help users improve their understanding of safe digital practices.


# Core Features

###  Cybersecurity Awareness Support

Provides users with educational guidance on key cybersecurity topics, helping promote safer online behaviour and digital awareness.

###  Interactive Chat Experience

Users can communicate with the chatbot through a modern graphical interface designed for simplicity and ease of use.

###  Personalized User Memory

The application remembers user interests and favourite cybersecurity topics to create a more tailored experience.

###  Sentiment Recognition

Detects user emotions such as concern, curiosity, or frustration and adapts responses appropriately to improve engagement.

###  Topic-Based Education

CyberGuard currently provides guidance on:

* Password Safety
* Phishing Awareness
* Malware Protection
* Online Privacy
* Scam Prevention
* Social Engineering
* Safe Browsing Practices

###  Live Interaction Statistics

Displays useful session information including:

* Number of questions asked
* User name
* Favourite topic
* Last discussed topic
* Current detected mood

###  Audio Greeting Functionality

Plays a welcome greeting audio when the application launches to enhance the user experience.

###  Professional User Interface

Built with Windows Forms using a clean layout, intuitive navigation, and user-friendly controls.

# Business Value & Purpose

CyberGuard was developed to address the growing need for cybersecurity awareness in an increasingly digital world. Many users remain vulnerable to threats such as phishing, scams, malware, and weak password practices due to limited cybersecurity knowledge.

This application helps bridge that gap by delivering cybersecurity education in a simple, conversational, and engaging format.

### Key Benefits

* Supports educational and training environments
* Provides beginner-friendly cybersecurity guidance
* Enhances user engagement through personalization

CyberGuard is suitable for:

* Educational institutions
* Cybersecurity awareness campaigns
* Beginner IT training programs
* Small business awareness initiatives
* Personal cybersecurity learning

# How to Launch the Application

## Step 1 — Open the Project

1. Launch **Visual Studio**.
2. Select **Open Project/Solution**.
3. Open the CyberGuard solution file (`.sln`).


## Step 2 — Build the Application

1. Navigate to the top menu.
2. Select:
   **Build → Build Solution**


## Step 3 — Run the Application

Press one of the following:

* `F5` → Run with debugging
* `Ctrl + F5` → Run without debugging

The CyberGuard application window will launch automatically.


## Step 4 — Start Using CyberGuard

1. Enter your name.
2. Type a cybersecurity-related question.
3. Receive educational guidance and awareness tips instantly.

### Example Questions

* “How can I create a strong password?”
* “What is phishing?”
* “How do I stay safe online?”
* “Tell me about malware.”
